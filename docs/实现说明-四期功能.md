## 2. 待 PHP 环境验证（本机未装 PHP/Composer，以下命令需在带 PHP 的服务器或开发机执行）

```bash
# 1. 安装依赖（如已装可跳过）
composer install --no-dev --optimize-autoloader --ignore-platform-req=ext-fileinfo

# 2. 配置 .env（如已存在跳过）
cp .env.example .env && php artisan key:generate

# 3. 运行迁移（新增 entrepreneurs 字段 + settings 表）
php artisan migrate --force

# 4. 清缓存并验证路由
php artisan route:clear && php artisan route:list | grep -E "featured|settings"

# 5. 运行测试（新增 3 个测试文件 + 原有用例）
php artisan test

# 6. 本地起服人工验证
php artisan serve
#   - 个人中心 → 申请推荐弹窗 → 提交理由 → 后台「推荐申请」标签审核
#   - 被拒后 15 天内再次申请被拦截
#   - 汉堡菜单开合 / 退出账户
#   - 系统设置保存后前台 title/og/footer 变化
```

> 注意：测试环境使用 sqlite in-memory + array cache（phpunit.xml 已配置），
> 但迁移文件含 `Schema::table('entrepreneurs', ...)` 的增量迁移，sqlite 支持 `after()` 为 no-op，可正常执行。

## 4. 已知注意点

1. **`Setting::get()` 在迁移前调用**：已做 `try/catch` 兜底，settings 表不存在时返回默认值，不会导致整站 500；但仍建议先 `migrate` 再访问。
2. **分享图绝对 URL**：og:image 存储/渲染均为绝对地址，微信爬虫可识别。
3. **汉堡 z-index**：菜单 `z-[200]`，二维码弹窗与城市选择器 `z-[300]` 仍在其上（符合预期）。
4. **空设置处理**：后台保存时空字符串存为 null，`Setting::get()` 的 `?? ` 兜底默认值生效（清空备案号/分享图即回退默认）。
