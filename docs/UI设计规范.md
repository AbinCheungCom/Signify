# Signify UI 设计规范

> 企业家形象资产数字化系统 · **高端编辑 / 杂志风**
>
> - 配套：`UI设计页面清单.md`（13 页）· `重构开发文档.md` v2.0（方案B 落地）
> - 版本：v1.0 · 2026-08-13 · 状态：方向已定，待设计稿验证

---

## 1. 设计方向与原则

**一句话**：让平台像一本高端商业杂志——**暖白纸感、衬线大标题、大幅留白、摄影主导、细分割线**。企业家的形象在留白与光影中被尊重地展示。

| 原则 | 说明 |
|---|---|
| **摄影主导** | 企业家肖像/形象图是页面主角，UI 让位不抢戏 |
| **留白即排版** | 大留白制造高级感，信息密度低、呼吸感强 |
| **衬线标题** | 标题用衬线（宋体系）传达"格调/可信"，正文用无衬线保证可读 |
| **分割线叙事** | 用 1px 暖色细线做分区，代替大块色块和阴影 |
| **单点强调** | 全站只用一个编辑红作强调色，其余克制在暖黑白灰内 |
| **印刷感** | 直角、细线、无重投影——像纸面而非 SaaS |

**适用范围**：公开页（首页/名录/详情/认证）全量应用；后台页（审核/管理）沿用同一色板与字体，但密度更高、更工具化。

## 2. 设计 Tokens

### 2.1 色板

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#FAFAF7` | 页面底色（暖白、纸感） |
| `--surface` | `#FFFFFF` | 卡片、浮层、输入区 |
| `--ink` | `#1A1A18` | 主文字、主按钮（暖黑，非纯黑） |
| `--ink-soft` | `#4A4A45` | 次文字 |
| `--muted` | `#8A8A82` | 元数据、弱化文字 |
| `--hairline` | `rgba(26,26,24,0.10)` | 分割线、描边 |
| `--hairline-strong` | `rgba(26,26,24,0.18)` | hover 描边、强调分割 |
| `--accent` | `#B3392C` | **编辑红**：链接、强调、"本期推荐"标题标记、focus |
| `--success` | `#2F6B4F` | 已通过 |
| `--warning` | `#A8791E` | 待审核（琥珀） |
| `--danger` | `#B3392C` | 已拒绝（复用编辑红） |

> **规则**：全站只有一个强调色（编辑红）。「推荐」标签用**墨黑实心**（编辑风），编辑红留给强调/链接/状态，避免红黑混用造成两套强调。

### 2.2 字体与字阶

| 角色 | 字体 | 权重 |
|---|---|---|
| 展示标题（serif） | `"Playfair Display", "Noto Serif SC", "Songti SC", Georgia, serif` | 700 / 900 |
| 正文（sans） | `"Inter", "Noto Sans SC", system-ui, "PingFang SC", "Microsoft YaHei", sans-serif` | 400 / 500 / 700 |
| 标签/元数据 | 同正文 sans，`uppercase + letter-spacing 0.08em` | 400 / 500 |

**字阶（fluid clamp，编辑风大标题）**：

| 级别 | 尺寸 | 行高 | 用途 |
|---|---|---|---|
| display-xl | `clamp(44px, 6vw, 72px)` serif | 1.15 | 首页巨型标题 |
| display-lg | `clamp(32px, 4vw, 48px)` serif | 1.2 | 页级标题 |
| display-md | `clamp(24px, 2.6vw, 34px)` serif | 1.25 | 区块标题、详情姓名 |
| title | 18-20px serif | 1.35 | 卡片姓名 |
| body | 14-15px sans | 1.6 | 正文、简介 |
| caption | 12px sans uppercase | 1.5 | 标签、日期、元数据 |

**字体加载策略**：从 `fonts.googleapis.cn` 加载（与 ABIN 站同基础设施），仅取标题用 `Playfair Display 700/900 + Noto Serif SC 700/900`、正文 `Noto Sans SC 400/500`；系统字体兜底，失败不影响排版。

### 2.3 间距 / 圆角 / 阴影 / 动效 / 分割线

| 维度 | 规范 |
|---|---|
| 间距 | 8px 基准：`4/8/12/16/24/32/48/64/96`；区块纵向留白 `py-16~py-24` |
| 容器 | `max-w-6xl`（1140）文本页、`max-w-7xl`（1280）名录/后台 |
| 圆角 | 卡片/按钮 **0**（直角印刷感）；头像 `50%`；输入框 0；小标签 `2px` |
| 阴影 | 极简：浮层（弹窗/下拉）`0 2px 16px rgba(26,26,24,0.08)`；常态靠 hairline 分隔 |
| 分割线 | 1px `--hairline`；横向贯穿式、起止对齐容器边（杂志式满宽分隔） |
| 动效 | `150-250ms ease-out`；hover：按钮 bg 微变、链接 opacity、卡片内图片 `scale(1.02) 400ms` |
| 无障碍 | 正文/背景对比度 ≥ 4.5:1（ink on paper）；focus 用 2px 编辑红 outline |

### 2.4 Tailwind tokens（落地映射，方案B 直接使用）

```js
// tailwind.config.js（节选）
theme: {
  extend: {
    colors: {
      paper:   '#FAFAF7',
      surface: '#FFFFFF',
      ink:     { DEFAULT: '#1A1A18', soft: '#4A4A45' },
      muted:   '#8A8A82',
      hairline:{ DEFAULT: 'rgba(26,26,24,0.10)', strong: 'rgba(26,26,24,0.18)' },
      accent:  '#B3392C',
      status:  { success: '#2F6B4F', warning: '#A8791E', danger: '#B3392C' },
    },
    fontFamily: {
      display: ['"Playfair Display"', '"Noto Serif SC"', 'Georgia', 'serif'],
      sans:    ['"Inter"', '"Noto Sans SC"', 'system-ui', 'sans-serif'],
    },
    fontSize: {
      'display-xl': 'clamp(44px, 6vw, 72px)',
      'display-lg': 'clamp(32px, 4vw, 48px)',
      'display-md': 'clamp(24px, 2.6vw, 34px)',
    },
    borderRadius: { '2px': '2px' },
    boxShadow: {
      float: '0 2px 16px rgba(26,26,24,0.08)',
    },
  },
}
```

## 3. 组件视觉规范

### 3.1 导航栏

- **公开页**：纸色底 + `blur(12px)`；左 `SIGNIFY`（serif，小标距）；右导航项用 `caption` 标签（12px uppercase）；当前页用 hairline 下划线标记；底部分割线。
- **后台**：同色系，导航项为「待审核 / 全部企业家」，右侧「返回首页」。

### 3.2 按钮

| 变体 | 样式 |
|---|---|
| 主按钮 | 墨黑实心 + paper 字 + 直角 + hover 微亮（`rgba(26,26,24,0.85)`） |
| 次按钮 | 透明 + hairline-strong 描边 + ink 字 |
| 幽灵 | 无描边文字按钮，hover 加 hairline 底 |
| 危险/通过 | 审核操作：通过=主按钮；拒绝=次按钮（编辑风不滥用红） |
| 禁用 | `--muted` + 降透明度 |

### 3.3 表单

- 输入框：**下划线式**（仅底边 1px hairline，focus 变 ink）——杂志感；后台表格内用 hairline 盒装。
- 校验错误：底边 1px 编辑红 + caption 级错误文案。
- 下拉/日期同款下划线；搜索框同款。

### 3.4 企业家卡片

```
┌────────────────────────────┐
│        （3:2 肖像图）        │  ← 图上 1px hairline 描边
│  ┌──────────────┐          │
│  │ 张斌 · 文化符号方法论     │  ← serif title
│  │ 北京 · 品牌战略  CAPTION  │  ← 12px uppercase
│  │ 推荐           墨黑实心标签 │
└────────────────────────────┘
```

- 名片：白卡 + 1px hairline 描边 + **0 圆角**；hover 图片 `scale(1.02)`；「推荐」= 墨黑实心标签。

### 3.5 状态徽章（审核流）

| 状态 | 样式 |
|---|---|
| 待审核 | 琥珀 `#A8791E` 文字 + hairline 描边 |
| 已通过 | 墨绿 `#2F6B4F` 文字 + hairline 描边 |
| 已拒绝 | 编辑红 `#B3392C` 文字 + hairline 描边 |
| 推荐 | 墨黑实心（与状态色区分） |

### 3.6 分页 / Flash / 弹窗 / 空态 / 头像上传

| 组件 | 规范 |
|---|---|
| 分页 | 「上一页 · 第 N 页 · 下一页」caption 级，hover hairline 底 |
| Flash | 成功/错误：hairline 框 + 左边线（成功=墨绿、错误=编辑红），放置于内容顶部 |
| 弹窗确认 | 纸色浮层 + hairline + 主/次按钮；阴影用 `float`；操作对象名称用 serif 加粗 |
| 空态 | serif 一句引导语 + caption 补充说明（如"暂无待审核申请"） |
| 头像上传 | 方形虚线 hairline 区，居中 + 上传说明；成功后显示预览 |

## 4. 页面基调（编辑风应用）

| 页面 | 基调 |
|---|---|
| 首页 | `display-xl` serif 大标题 + 一句主文案；下方 1-2 个横贯的"本期推荐"企业家大图模块（左右图/文版式，杂志跨页感） |
| 名录 | 顶部页级标题 + 下划线筛选行；3 列卡片网格，大留白 |
| 详情 | 左大肖像图 / 右 serif 姓名 + caption 元数据 + 简介（分栏版式）；联系方式低调展示 |
| 认证页 | 居中单栏：serif 标题 + 下划线表单，纸感强 |
| 个人中心 | 同上纸感；头像上传区突出 |
| 后台 | 同色板，密度提高：统计卡（纸卡 + 大数字 serif）、hairline 表格、批量操作行 |
| Setup | 三步向导，纸感表单 + 状态说明 |
