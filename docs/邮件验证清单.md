## 一、前置确认（3 项）

- [ ] 代码已同步：`git fetch origin && git reset --hard origin/main`（当前 HEAD 应为 `df9b984`）
- [ ] `.env` 已含 `MAIL_*` 配置（smtp.qq.com / 465 / ssl / QQ邮箱 / 16位授权码）
- [ ] `.env` 的 `APP_URL=https://chat.ihote.com`（重置链接靠它拼完整地址）

## 二、执行（按顺序）

```bash
cd /www/wwwroot/chat.ihote.com

# 1. 建 password_reset_tokens 表（缺失会导致重置 500）
php artisan migrate --force

# 2. MAIL_* 加进 .env 后必须刷配置缓存（部署铁律）
php artisan config:cache
```

## 三、发信验证（两步）

### 3.1 命令行直测 SMTP（不依赖浏览器，最快定位）

```bash
php artisan tinker --execute="
try {
  Mail::raw('Signify SMTP 配置测试，收到即正常。', function (\$m) {
    \$m->to('填写收件邮箱@xx.com')->subject('Signify 邮件测试');
  });
  echo 'SENT_OK';
} catch (\Exception \$e) {
  echo 'SEND_FAIL: ' . \$e->getMessage();
}"
```

- 输出 `SENT_OK` → SMTP 配置成功，进 3.2
- 输出 `SEND_FAIL: ...` → 把冒号后的报错发回（常见：授权码错误 / 端口不通 / SSL 证书）

### 3.2 Web 流程验证（完整闭环）

1. 打开 `https://chat.ihote.com/forgot-password` → 输入一个已注册邮箱 → 提交
2. 到该邮箱收信 → 点「重置密码」链接
3. 设新密码 → 用新密码登录成功
